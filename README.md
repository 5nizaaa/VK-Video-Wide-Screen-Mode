# VK Video Wide-Screen Mode

Расширение для Chrome/Chromium — аналог «YouTube Wide-Screen Mode Enhancer», но для **vkvideo.ru**.

Включает «широкоэкранный» (театральный) режим: плеер занимает всю ширину окна браузера,
высота = окно минус фиксированная шапка (48px). Заголовок, описание и комментарии остаются
доступны ниже — плеер просто прокручивается вверх, как в театральном режиме YouTube.

Своих кнопок расширение **не добавляет**: переключателем служит родная кнопка плеера
со стрелками (театральный режим VK) в правой части панели управления. Расширение
«дожимает» этот режим — родной театр VK оставляет плеер низким (по пропорции видео),
а расширение растягивает его на всё окно.

## Управление

| Способ | Действие |
|---|---|
| Родная кнопка со стрелками в панели плеера (справа) | вкл/выкл широкий режим |
| Клавиша **T** (родная горячая клавиша театрального режима) | вкл/выкл широкий режим |
| Клик по иконке расширения на панели браузера | вкл/выкл широкий режим |

Состояние хранит сам VK (театральный режим — настройка плеера). При включении режима
(и при переходе к следующему видео, пока режим включён) страница автоматически
прокручивается наверх — плеер занимает весь экран, как в театральном режиме YouTube;
заголовок и комментарии остаются ниже, до них можно доскроллить.

## Установка (unpacked)

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (справа вверху).
3. Нажмите «Загрузить распакованное расширение» и выберите папку `vkvideo-wide-screen`
   (или нажмите «Обновить» на карточке уже установленного расширения).
4. Откройте любое видео на https://vkvideo.ru/ и нажмите **T** (или кнопку со стрелками).

Для Firefox: переименовать ключи манифеста (`background.service_worker` → `background.scripts`)
и загрузить как временного дополнения — либо собрать через web-ext. В комплекте — только Chrome-версия.

## Как это работает

- Панель управления плеера VK отрисована в Shadow DOM у `div.shadow-root-container`;
  там живёт родная кнопка театрального режима — `button[data-testid^="theater-mode"]`
  (`theater-mode-on` = театр включён, `theater-mode-off` = обычный экран).
- `content.js` следит за состоянием этой кнопки (клик, смена `data-testid`, MutationObserver
  и запасной интервал) и зеркалит его классом `vws-on` на `<html>`, размечает страницу
  (классы `vws-main` / `vws-hide` / `vws-unpad`, т.к. классы VKUI содержат нестабильные хеши)
  и переживает SPA-навигацию.
- `content.css` — CSS широкого режима (всё под ключом `html.vws-on`, поэтому выключается
  мгновенно): скрывает левое меню и правый сайдбар, растягивает колонку и плеер
  (`height: calc(100vh - 48px)`, снимает `max-height` и `aspect-ratio` VKUI). В театральном
  режиме VK выносит плеер из колонки страницы, поэтому селектор плеера не привязан к `.vws-main`.
- `background.js` — клик по иконке на панели шлёт сообщение в контент-скрипт, тот «нажимает»
  родную кнопку театрального режима.

## Файлы

```
vkvideo-wide-screen/
├── manifest.json    — манифест MV3
├── content.css      — стили широкого режима
├── content.js       — логика: слежение за родной кнопкой, разметка, SPA
├── background.js    — клик по иконке расширения
```
